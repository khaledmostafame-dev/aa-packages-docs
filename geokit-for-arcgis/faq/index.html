FAQ

Do I need an ArcGIS account?

Section titled “Do I need an ArcGIS account?”

Not for public services: Connect has an anonymous mode, which is how the sample bot runs. For the ArcGIS World geocoder, routing, places and your own content you need an ArcGIS Online, Location Platform or Enterprise account and an API key, a username/password or app credentials. The offline and geometry actions need an Esri account to download the ArcGIS Maps SDK.

Why do the offline and geometry actions need an SDK download?

Section titled “Why do the offline and geometry actions need an SDK download?”

The package contains no Esri software. Those 16 offline and geometry actions run on the ArcGIS Maps SDK for Java, which you download from developers.arcgis.com with your own Esri account. Download ArcGIS Maps SDK for Java 200.6 (Windows) from developers.arcgis.com with your own Esri account (a later 200.x also works), extract it on the Bot Agent machine, and run Set ArcGIS SDK Folder with the extracted folder - the one that holds libs, jniLibs and resources - before the first offline or geometry action. Setting the GEOKIT_ARCGIS_SDK environment variable for the Bot Agent does the same. The online actions need no download.

Where is my API key kept?

Section titled “Where is my API key kept?”

Bind it to Connect’s Credential field from the Credential Vault. Connect keeps it in the Bot Agent’s memory and returns only an opaque connectionId; the key never appears in a bot variable. Get Access Token returns the current token for other packages; treat its output as a secret.

Do I need a license for the offline and geometry actions?

Section titled “Do I need a license for the offline and geometry actions?”

For production, yes: your own ArcGIS Maps SDK license string from Esri, applied with Set Runtime License. Lite is free and covers geocoding, routing, geometry and reprojection; shapefiles and GeoPackages need Standard. Without a license string the actions run in Developer mode, which is not licensed for production.

Does the package include an Esri license?

Section titled “Does the package include an Esri license?”

No. It contains no Esri software and does not sublicense Esri software. Each customer downloads and licenses the SDK, and uses the online services, directly under Esri’s terms.

Why does the package start a separate process?

Section titled “Why does the package start a separate process?”

The ArcGIS Maps SDK for Java needs Java 17 and the Bot Agent runs Java 11. The offline and geometry actions therefore run in a Java 17 engine on your SDK, started as a local child process on first use. It communicates through its standard input and output, opens no network port, and stops after 15 idle minutes or when Release Offline Data is called with a blank path.

Can I use ArcGIS Enterprise?

Section titled “Can I use ArcGIS Enterprise?”

Yes. Give Connect your portal URL (https://host/portal) or an ArcGIS Server URL (https://host/arcgis). The routing and geocoding actions also accept a Service URL that points at any compatible service.

Does it work on macOS or Linux Bot Agents?

Section titled “Does it work on macOS or Linux Bot Agents?”

No. The package declares Windows only; its offline engine uses the SDK’s Windows native libraries.

What do Esri’s attribution rules mean for Export Map Image?

Section titled “What do Esri’s attribution rules mean for Export Map Image?”

The image always carries “Powered by Esri” and the map service’s copyright text, drawn by the action itself. Keep it on the image when you publish it.

Where are the logs?

Section titled “Where are the logs?”

Online errors come back as the action’s error message. The offline engine writes %LOCALAPPDATA%\GeoKitArcGIS\engine.log under the Bot Agent user’s profile.
