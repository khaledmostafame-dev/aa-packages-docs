Classify File

Extract text from a PDF/image/DOCX/TXT (digital layer first, OCR fallback) and classify it using a trained model file.

Inputs

Section titled “Inputs”
InputTypeRequiredAccepts
File pathFileYes
Classifier model file (.json from Train Classifier)FileYes
Deterministic rules (one per line: ‘Label: keyword1, keyword2’) - checked before the modelText (multi-line)—
OCR script (for scanned pages/images)Choice—Auto (English + Latin) · English · Latin (French, German, Spanish, …) · Arabic · English + Latin + Arabic
PDF page range (e.g. 1-3)Text—
Unclassified below confidence % (blank = use model’s saved threshold)Number—

Returns

Section titled “Returns”

Dictionary — Assign the result {fileName, label, confidence, scores} to a dictionary variable

Part of the Classify group.
